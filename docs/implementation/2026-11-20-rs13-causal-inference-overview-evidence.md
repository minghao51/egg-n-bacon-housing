1. **A dated policy artefact** — machine-readable rows pinning event identifier, event date, and the segment/population scope each event applies to (`presentInCheckout: false`; scan: zero file matches, §6a).

These are requirements a future reconstruction would have to satisfy. This pack does not schedule one, design one, or approximate one.
