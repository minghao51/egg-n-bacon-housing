## What the numbers are, and are not

There are two different kinds of numeric content in this edition. First are measurements derived for this edition from the pinned checkout: frame inventory, cutoff counts, and screens of cohort size and label spans. These are measurements of what the current dataset and named columns contain. Second are values printed by the legacy article or image. These remain frozen-source claims; the two causal headline values are explicitly withdrawn and none of the old values is presented as a newly computed result (`legacyClaims`, `withdrawals`).

A screen is a description of a series or group under the stated filter. It is not evidence about the origin of the series, the logic that assigned treatment, or the execution of a causal model. The shipped `market_segment` column can be described and its planning-area spans counted. That cannot recover the retired classifier or establish that the old estimator used these labels (`cohortScreens.segmentAreaSpans.meaning`, `identificationAudit.treatmentControlConstruction.specificationProse`). Similarly, satisfying a stated row-count floor only screens sample size. It does not show that a regression was executed or that any causal assumptions hold (`cohortScreens.diD.floorSatisfiedByStatedGroups`, `cohortScreens.rdit.floorSatisfiedByEveryWindowMonth`).

“Withdrawn” and “not reproducible” are not synonyms. The two headline causal amounts were withdrawn by the recorded disposition; the stated unit, timing and population are the legacy text's wording and are not independently verified. The lease-band assertions, event-date descriptions, formula statements, and robustness claim are not reproducible from this checkout and are not thereby established false (`withdrawals.condoDid.statedUnit`, `withdrawals.hdbRdit.statedUnit`, `leaseMispricing.meaning`, `notMeasurable.meaning`). No unit, sample window, or population is selected where the legacy wording leaves it underspecified (`notMeasurable.theTwoHeadlineNumbers`).

The plot requires the same restraint. The pinned image visibly prints a title, a DiD annotation and pre/post percentage labels. It has no sample window, observation count, bandwidth or run identifier. Although the frozen manifest lists the image, no run identifier, estimator output or code links its pixels to the headline estimates. The unlinked plot is evidence neither for nor against the withdrawn estimates; visual similarity of its rounded annotation to a withdrawn amount changes neither direction (`unlinkedArtefact.linkage`, `unlinkedArtefact.visibleAnnotations`, `unlinkedArtefact.manifestPin`). An asset manifest entry is not an estimator record.
