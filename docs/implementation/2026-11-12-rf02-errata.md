## 3. Chart rendering fixes

- `ComparisonChart` passed `layout="horizontal"` (Recharts draws *vertical* bars) while configuring a numeric X axis and category Y axis, so no bar geometry was produced. Layout is now the inverse of the intent; bars render.
- `InlineChartRenderer` now drops datasets whose values are all missing and prints which columns were not charted, instead of plotting an empty legend entry.
- Comparison charts are split **one per unit** (S$ / percentage / transaction count), because a count of 7,585 and a premium of −$16.88 cannot share an axis.
- A marker whose columns are missing or text-only now renders an explanatory note rather than disappearing silently.
- The `lease-decay` chart gate is unchanged: that study still renders tables and no charts.
